## LenaLashes Workspace backend

### Backend Folder Structure

backend/
  src/
    config/
    controllers/
    middleware/
    models/
    routes/
    app.ts
    server.ts

### Tech Stack

* Node.js
* Express
* TypeScript
* REST API

### Installation / Running / Build

* Install all project dependencies:
% npm install

* Start development server:
% npm run dev

* For build use:
% npm run build

### Environment Variables

Create .env file in the backend folder and add:

DATABASE_URL=your_database_connection_string
