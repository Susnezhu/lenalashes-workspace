# LenaLashes Workspace - Features

## Authentication and Users

* Login and logout
* Admin and Employee roles
* Employee management
* Employee activation and deactivation
* Role-based access control

## Dashboard

* Personal tasks
* Active announcements
* Current cleaning responsibility
* Important inventory alerts
* Pending actions for the administrator: notes or gifts
* Employee bonus information
* Recent actions in history


## Cleaning Management

* Weekly cleaning schedule
* Admin-only schedule management
* Information about the latest person who completed the cleaning
* Personal cleaning checklist
* Weekly automatic checklist reset
* Editable list of cleaning responsibilities

## Tasks

* Admin can create personal tasks for employees
* Employees can mark their tasks as completed
* Completed tasks disappear from the employee dashboard
* Completed tasks are available in the admin history
* Admin can delete an incorrectly created task before employee confirmation

## Announcements

* Admin can create announcements
* Announcements can be activated or deactivated
* Inactive announcements are not shown to employees
* Announcements can be deleted

## Inventory

The inventory is divided into three separate areas:

* Online store products
* Salon supplies
* General salon supplies

Inventory features include:

* Product images
* Product categories
* Current quantity
* Quick quantity editing
* Save action by confirming changes
* "Low stock" and "out of stock" status
* Selected inventory category shown on the main dashboard
* Weekly inventory checking by the employee responsible for cleaning

## Employee Bonuses

* Admin manually gives bonus points
* Employees have a personal bonus balance
* Admin manages the gift catalogue
* Gifts have images, names and descriptions
* Employees can use bonus points to select a gift
* Gift selection creates a pending action for the admin
* The admin dashboard keeps the reminder visible until the gift has been given
* Admin can mark the gift as given

## Languages

The application supports:

* Finnish
* English
* Russian
