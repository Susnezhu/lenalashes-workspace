## LenaLashes Workspace Frontend

This folder include all frontend data

### Frontend Folder Structure

frontend/
  src/
    assets/
    components/
    pages/
    services/
    theme/
    types/
    App.tsx
    main.tsx
    vite-env.d.ts

### Tech Stack

* React
* TypeScript
* Vite
* MUI
* PWA

### Installation / Running / Build

* Install all project dependencies:
% npm install

* Start development server:
% npm run dev

* For build use:
% npm run build

### Env Variables

Create .env file in the frontend folder and add:

VITE_API_URL=http://localhost:3000
