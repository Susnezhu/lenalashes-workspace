# LenaLashes Workspace

LenaLashes Workspace is a private mobile Progressive Web App (PWA) designed for the daily internal work of a small beauty salon.

The application has employee tasks, cleaning schedules, internal announcements, inventory management and employee bonuses in one place.

The application is made for use by LenaLashes employees only and is not planned as a public application.

The application does not replace:

* Timma
* Online store
* SumUp
* Existing public website

It is an additional internal tool for the salon.


## Project Goals

The main goals of the application are:

* Centralize internal salon information.
* Reduce manual work for the owner.
* Make the inventory easier and faster to update.
* Make employee tasks and announcements visible in one place.
* Organize weekly cleaning responsibilities.
* Provide a simple manual bonus system.
* Create a mobile experience suitable for both iPhone and Android


## Main Features

The application includes:

* Employee management
* Cleaning management
* Tasks and announcements
* Inventory management
* Employee bonuses and gift shop
* Finnish, english and russian languages

Demo users and data should be used in screenshots and portfolio materials.
